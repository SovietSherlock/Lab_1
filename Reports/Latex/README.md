# LaTeX-исходники отчётов

Исходники:

- `report_baryshev_AA.tex` — отчёт Барышева А.А.;
- `report_baryshev_SA.tex` — отчёт Барышева С.А.

Документы набираются шрифтом Times New Roman, с полями 30/15/20/20 мм,
междустрочным интервалом 1,5 и абзацным отступом 1,25 см. Графики подключаются
из `Results/Graphs` как отдельные иллюстрации; страницы отчёта не являются
растровыми изображениями.

Сборка из каталога `Reports/Latex`:

```text
tectonic report_baryshev_AA.tex
tectonic report_baryshev_SA.tex
```
